# xcpc-archive

历年国内算法竞赛补题集锦：收录 ICPC / CCPC 各赛站，以及蓝桥杯、天梯赛、CSP 等赛事的题面、重现赛与补题入口，一年一个文件归档。

*A yearly archive of contest links for Chinese algorithmic competitions.*

| 年份 | 文件 | 主要赛事 |

> 新赛季在仓库根目录新建 `YYYYXCPC补题链接集锦.md`，并在上表加一行。

## 收录范围

- **ICPC**：亚洲区域赛国内赛站、EC-Final、全国邀请赛、省赛
- **CCPC**：国赛、全国邀请赛、女生赛 / 高职赛、总决赛
- **其他**：蓝桥杯、百度之星、天梯赛（GPLT）、CACC、CSP 认证

## 链接约定

- 题面与补题优先给 OJ 入口：[QOJ](https://qoj.ac)、[洛谷](https://www.luogu.com.cn)、Codeforces Gym；官网仅用于确认赛程与报名
- 同一场比赛尽力给多个可用入口

## 说明

链接以官方与 OJ 实际页面为准。发现失效、错链或赛程变更，欢迎提 issue 或直接 PR。
